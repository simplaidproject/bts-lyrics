# 보라해 · Borahae — BTS Lyrics

An offline-first lyric book and setlist builder for BTS: Korean lyrics,
romanization and English, word-level synced lyrics, a concert mode and a
light stick. Open it once on wifi; after that it works in airplane mode.

- 100% static — no build step, no backend, no tracking.
- A service worker caches the whole book (52 files) on first visit.
- The Content Security Policy in `index.html` blocks every outbound connection.

Hosted with GitHub Pages from the `main` branch.

*Non-commercial fan project. Lyrics for personal reference; all words and
music belong to their rights holders. Cover art belongs to HYBE.*
